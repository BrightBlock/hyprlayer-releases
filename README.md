# Hyprlayer — Releases (archived)

New releases of **Hyprlayer Desktop** are published on
[BrightBlock/hyprlayer-desktop](https://github.com/BrightBlock/hyprlayer-desktop/releases/latest),
alongside its source.

This repo keeps the releases up to v0.8.23 so older installs keep working.
Installed apps update themselves; nothing here needs downloading by hand.
