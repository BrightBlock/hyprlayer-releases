# Hyprlayer — Releases

Downloadable builds of **Hyprlayer**, the native desktop app for spec-driven
development. Source code lives in a separate private repository; this repo
hosts only the release binaries so they're publicly downloadable.

## Install

Grab the latest build from the [Releases](https://github.com/BrightBlock/hyprlayer-releases/releases/latest) page:

- **macOS** (universal, Apple Silicon + Intel): download the `.dmg`.
- **Windows** (x64): download and run the `-setup.exe`.

After the first install the app keeps itself up to date via its built-in
updater — new releases are applied from inside the app.
